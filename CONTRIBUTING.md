# Contributing to Floating Clock Overlay

Thank you for your interest in improving Floating Clock Overlay.

---

## How to Contribute

Contributions are welcome for bug fixes, improvements, documentation, and feature suggestions.

- **Bug reports** — open an Issue describing the problem, steps to reproduce, and your macOS version.
- **Feature suggestions** — open an Issue tagged `enhancement`.
- **Pull requests** — for small fixes or improvements. Open an Issue first for larger changes so we can discuss the approach before you invest time.

---

## Ground Rules

1. **Language and stack** — contributions must remain in Swift / SwiftUI / AppKit. No Electron, JavaScript, Python, or web technology.
2. **Keep it focused** — this app is intentionally minimal. Additions should not significantly increase complexity or binary size without a clear benefit.
3. **Code style** — follow the existing style: meaningful names, minimal comments, no long docstrings.
4. **Test your changes** — make sure `make build` succeeds and the overlay still works correctly (transparent, always on top, click-through by default) before opening a PR.
