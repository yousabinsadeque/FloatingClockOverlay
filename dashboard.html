Deploy

Commands to build, package, and deploy your app and website.

📦 Build & Package New Version

Run these commands in Terminal to create a new DMG and deploy.

cd ~/Desktop/FloatingClockOverlay
make clean && make build
make package-dmg
🚀 Deploy Website to Firebase

Push website changes live.

firebase deploy --only hosting --project floating-clock-overlay
🐙 Push to GitHub

Commit and push all changes to GitHub.

git add -A && git commit -m 'Update' && git push
🏷️ Create New GitHub Release

Upload the new DMG as a GitHub Release. Change the version number as needed.

gh release create v1.1.0 --title '...' --notes '...' dist/FloatingClockOverlay.dmg
🔄 Full Update Workflow All Steps

Complete workflow: build, package, deploy website, push to GitHub, and create a release.

cd ~/Desktop/FloatingClockOverlay && make clean && make build && make package-dmg && firebase deploy && git add -A && git commit -m 'Release update' && git push

📝 How to Update

Update website content:

1. Edit firebase-public/index.html

2. Run firebase deploy


Release new app version:

1. Make code changes

2. Run make package-dmg

3. Run gh release create v1.x.0

4. Push to GitHub


Update both GitHub Pages & Firebase:

Edit both docs/index.html and firebase-public/index.html, then deploy both.
